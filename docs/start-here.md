# 公众号机制诊断 · 从这里开始

> 收到报告之前你只想知道三件事：我要做什么、多久拿到、多少钱。

## 你要做的（一步）

公众号后台 → **内容分析 → 已发表内容 → 全部** → 页面顶部「下载数据明细」→ 得到 Excel。

不要改任何东西，直接发我。这个文件含每篇文章的阅读人数和渠道来源（推荐 / 公众号消息）。
只导「已通知内容」列表往往只有总阅读、没有分渠道，那样跑不了。

## 交付什么

四类结构判定 + **断供窗检测** + 可比期分组 + 逐篇定位（推荐最高 3 篇 / 阅读最低 5 篇）+ 三条动作 + 不做清单。
每个数字带分母（n），你能用自己后台复算。

## 价格

| | 价格 | 交付 |
|---|---|---|
| 单号诊断 | ¥499 | 24 小时（收到数据起算） |
| 月度陪跑 | ¥1,999/月 | 每月 1 次诊断 + 4 次问答；30 天内转月度，诊断费全额抵扣 |
| 服务商（代运营/外包） | ¥149/号，5 号起 | 48 小时，可白标转给客户 |

## 承诺 / 不承诺

**承诺**：24h 内不出报告全额退；每个数字可复算。
**不承诺**：阅读量、涨粉、能不能被推荐——平台分发不受单方控制。
**拒单**：样本 <10 篇或发布不足 7 天，不出报告也不收钱。

## 开始

开个 issue 写「诊断」+ 你的号大概多少篇，或直接发邮件。样本长什么样见仓库 `SAMPLE.md`。

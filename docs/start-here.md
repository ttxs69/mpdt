# 公众号机制诊断 · 自助版

> 一个纯静态页面：你在浏览器里拖进公众号后台导出的表格，页面直接出报告。
> 数据全程在你的电脑上，不上传、不存储、无后端。

## 怎么用

1. 公众号后台 → **内容分析 → 已发表内容 → 全部** → 页面顶部「下载数据明细」→ 得到 Excel
   （注意要选「全部」而不是「已通知内容」；后者只有总阅读、没有分渠道，跑不了）
2. 打开下面的页面，把 .xlsx（或 .csv）拖进去
3. 页面出报告

## 报告给什么

四类结构判定 + **断供窗检测** + 可比期分组 + 逐篇定位（推荐最高 3 篇 / 阅读最低 5 篇）
+ 三条动作 + 不做清单。每个数字带分母（n），你能用自己后台复算。

## 人工服务已停

之前这里挂过付费的人工版，**现已停止接单**：
那些交付里的「逐篇改法」「为什么爆」「下一篇写什么」是结论型判断，
会随样本变化而漂移 —— 交付一个会变的结论，等于交付风险，不该收你的钱。

**所以：只提供自助版。** 自助版交付的全是**带分母的事实**，每个都能复算。
